Institutional Session Framework

The Logic: Time-Price Distillation

The script uses f_ParseAdjustTime to anchor volatility windows to New York local time, regardless of your exchange timezone. It isolates the Opening Range—the high and low of the first minutes of a session—using a sophisticated request.security call that fetches sub-minute data even when viewing higher timeframes.

The Visual Solution: The "Ghost" Opening Range

Through the SessBoxC1 logic, the indicator draws a secondary, lighter box within the main session. This highlights the Initial Balance (first 15/30/60m), allowing you to see if the session is trending away from its start or trapped in a range expansion.

The Tactical Edge: Session Raids

The f_CrossTm function tracks if the London High is raided by New York. If a raid occurs, the script prunes the old level and alerts you. This filters out "stale" levels and highlights active Liquidity Grabs in real-time.

03

RTH Structural Gaps

The Logic: The "Closing Bell" Anchor

The script anchors to 16:15 New York time (the true settlement for many futures). It captures RTH_Close0 and compares it to the 9:30 AM RTH_Open. This calculates the physical gap that needs to be "filled" for the market to return to equilibrium.

The Tactical Edge: 1/2 RTH Midpoint

A standout feature is the RTH_Avg. By calculating the mathematical mean between the previous close and the current open, the engine plots a 1/2 RTH level. Institutional algorithms often treat this 50% retracement of the gap as a primary "Fair Value" pivot.

The Visual Solution: Gap Directionality

Using OpenUp booleans, the script dynamically changes label icons (▲/▼) and placement. If the market opens above the prior close, it signals a "Gap Up" and tracks the RTH_Close as a support floor that, if broken, triggers a Gap Fill narrative.

Gap & Midpoint Calculation

// Calculate the RTH Gap and its 50% Midpoint
RTH_Open := Open
RTH_Avg  := math.avg(RTH_Close, RTH_Open)
OpenUp   := RTH_Open > RTH_Close

// Display Gap Magnitude
RTH_LabelTxt = OpenUp ? "▲ 𝗥𝗧𝗛" : "▼ 𝗥𝗧𝗛"
