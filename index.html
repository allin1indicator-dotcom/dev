Multi-Timeframe DWMQY Session Engine

Core Purpose

Tracks and visualizes Daily → Yearly sessions (DWMQY) with open/high/low/close, calculates ranges, manages raid/cross logic, and provides alerts. Supports multi-timeframe analysis.

Key Features

  • Session start/end detection per timeframe using timezone-anchored timestamps.
  • Computes session highs/lows using first-candle and historical references.
  • Maintains multi-timeframe persistence via arrays for current, previous, and secondary sessions.
  • Raid/cross logic triggers extended lines and dynamic alerts on extreme breaches.
  • Dynamic formatting for labels, boxes, and ranges per session/timeframe.
  • Modular functions like f_SessionNB_HL, f_ExtendLines, f_DWMQY.

Visual / Chart Behavior

  • Session high/low lines extended across chart; optional boxes for raid/cross events.
  • Labels display session ranges, first-candle extremes, and alerts.
  • Multi-level plotting: separate arrays/lines for current, previous, secondary session extremes.
  • Text overlays for H/L per timeframe: PD, PW, PM, PQ, PY.
  • Dynamic hiding and extension of lines reduces clutter.
  • First-candle and previous-session memory (_High1, _Low1, _High2, _Low2) for context.

Triggers / State Changes

  • _NB triggers session start; x_NB triggers session end.
  • Cross detection (HCross, LCross) triggers when price breaches previous session highs/lows.
  • Raid/cross logic activates extended lines and labels conditionally per session/timeframe.
  • Handles multi-day/week/month adjustments and gaps for alignment.
Example Module Two

Core Purpose

Example module for intraday range visualization and alerting.

Key Features

  • Tracks high/low ranges per session.
  • Pushes lines and labels dynamically.
  • Alert triggers on range breakout.

Visual / Chart Behavior

  • Lines extend for visible range.
  • Optional boxes highlight breakout zones.
  • Labels display session extremes.

Triggers / State Changes

  • Breakout detection triggers alerts.
  • Conditional label updates per session end.
Example Module Three

Core Purpose

Demonstrates multi-timeframe alerting logic with persistent chart markers.

Key Features

  • Stores alert markers in arrays for multiple timeframes.
  • Dynamic formatting of marker color and text.
  • Conditional alerting based on previous session extremes.

Visual / Chart Behavior

  • Persistent markers on chart across timeframe changes.
  • Optional highlighting for extreme events.
  • Dynamic label updates tied to price action.

Triggers / State Changes

  • Alerts trigger when price breaches stored extremes.
  • Markers update only on timeframe or session changes.
